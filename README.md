СТУДИЯ:
Dorozee Studio - студия для разработки сайтов

КОМПОНЕНТЫ:
Header, Footer - вынесены в общий layout, чтобы не дублировать разметку
Hero - отдельная секция главной
Section - единый контейнер с ритмом отступов для всех страниц
Card - переиспользуемая карточка услуги

ЗАКРЕПЛЕНИЕ ШАПКИ:
Использован sticky. Шапка остаётся в потоке документа, поэтому контент не перекрывается и компенсирующий отступ сверху не нужен. Fixed потребовал бы вручную задавать padding top для main
